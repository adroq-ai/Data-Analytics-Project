# 📊 Sales Insights – Brick and Mortar Business (Power BI & SQL)

## 🧾 Project Overview
This project analyzes the sales performance of **AtliQ Hardware**, a brick-and-mortar retail business.  
The goal was to use **SQL** for data cleaning, querying, and analysis, and then visualize the results using **Power BI** to better understand sales trends and improve business decision-making.

---

## 🎯 Objectives
- Clean and analyze AtliQ Hardware’s sales data using SQL  
- Identify key sales trends, top-performing products, and regional performance  
- Visualize insights through an interactive Power BI dashboard  
- Help stakeholders make data-driven business decisions  

---

## 🧠 Tools & Technologies
- **SQL** – Data cleaning, querying, and analysis  
- **Power BI** – Data visualization and dashboard creation 

---

## 🧩 Process

### 1. Data Cleaning (SQL)
- Removed duplicates, handled missing values, and standardized entries  
- Ensured data consistency and accuracy across all tables  

### 2. Data Analysis (SQL)
- Queried key business metrics such as total sales, profit, and customer performance  
- Generated summarized tables for product, region, and time-based analysis  

### 3. Visualization (Power BI)
- Imported analyzed SQL results into Power BI  
- Designed an interactive dashboard to display trends, KPIs, and category insights  
- Enabled users to filter and explore data dynamically  

---

## 📈 Key Insights
- The **Power BI dashboard** clearly displayed AtliQ Hardware’s sales trends and performance metrics.  
- **SQL analysis** revealed high-performing regions and profitable product lines.  
- The final dashboard provided actionable insights that support data-driven business strategies.

## 💡 How to Use
1. Clone or download this repository  
2. Execute the SQL scripts for data cleaning and analysis  
3. Open `sales_insights.pbix` in Power BI  
4. Load the analyzed data and interact with the dashboard

## 🏁 Conclusion
This project showcases how combining **SQL** and **Power BI** can turn raw retail data into meaningful insights.  
By performing data cleaning and analysis in SQL and visualizing the results in Power BI, the **AtliQ Hardware Sales Insights Dashboard** enables informed, data-driven decision-making.
